# Java Primeros Pasos

Proyecto personal que utilicé para aprender lo básico de **Java**.
Cada archivo es un pequeño resumen con comentarios explicando cada concepto

## Contenido

- **Main** → consola, tipos de datos, `Scanner` y `try-catch`
- **Variables** → declarar variables y pedir valores
- **Condicionales** → `if`, `else` y operadores `&&` / `||`
- **Switch** → menú de opciones con `switch`
- **Bucles** → `for` y `while`
- **Arrays** → crear, recorrer y modificar arrays
- **Poo** → clases, objetos, constructores y métodos
